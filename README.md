## 📋 Overview

**PerfumeProject** is a premium luxury perfume e-commerce platform featuring smooth animations, multilingual support, detailed fragrance notes, volume selectors, and a polished shopping experience — built with the latest Next.js 15 App Router.

---

## ✨ Features

- 🌹 **Luxury product pages** — fragrance pyramid (top/heart/base notes), ingredient list
- 🌍 **Multilingual** — multiple language support with localized product data
- 🎨 **Premium animations** — smooth page transitions via Framer Motion
- 📦 **Volume selector** — 30ml / 50ml / 100ml with dynamic pricing
- 🛒 **Shopping cart** — add to cart, quantity management
- 🖼️ **Stock photography** — curated product imagery
- 📱 **Fully responsive** — mobile-first design

## 🚀 Quick Start

```bash
git clone https://github.com/daudbro73-collab/PerfumeProject.git
cd PerfumeProject
npm install
npm run dev
```

Open `http://localhost:3000`

### Production build

```bash
npm run build   # Next.js production build
npm run start   # Start production server
```
